# pi-pstack

A Pi port of Cursor's [pstack](https://github.com/cursor/plugins/tree/main/pstack) (poteto-mode playbooks, principles, multi-model panels), plus `deslop`, `control-ui`, and `control-cli` from cursor-team-kit, mechanically adapted to Pi paths. A bundled extension will supply the Cursor built-ins the skills rely on. See [UPSTREAM.md](./UPSTREAM.md) for what is vendored and how.

```sh
pi install git:github.com/KorenKrita/pi-pstack
```

**Work in progress:** the extension (`extensions/pstack/index.ts`) is not written yet.
